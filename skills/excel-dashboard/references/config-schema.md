# Схема `config.json`

Конфиг полностью определяет дашборд: `build_dashboard.py` не додумывает ничего,
кроме значений по умолчанию, перечисленных ниже. Все имена колонок пишутся ровно
так, как они пришли из `tabledata.py profile` (включая пробелы и запятые).

## Корень

| Поле | Тип | По умолчанию | Смысл |
|---|---|---|---|
| `title` | строка | имя листа/файла | Заголовок страницы и вкладки |
| `subtitle` | строка | — | Подпись под заголовком: период, объём выборки, источник |
| `theme` | `"light"` / `"dark"` | тема системы | Жёстко зафиксировать тему; кнопка «Тема» всё равно работает |
| `filters` | массив | `[]` | Панель фильтров |
| `kpis` | массив | `[]` | Строка карточек с числами |
| `charts` | массив | — | Сетка блоков; хотя бы один обязателен |

## filters

```json
{"column": "Регион", "type": "multiselect", "label": "Филиал"}
```

| Поле | Смысл |
|---|---|
| `column` | Колонка данных (обязательно) |
| `type` | `multiselect` · `range` · `daterange` · `search`. Если не задан — выбирается по типу колонки: дата → `daterange`, числовая мера → `range`, остальное → `multiselect` |
| `label` | Подпись, если название колонки в интерфейсе неудобно |

`multiselect` — список с поиском и кнопками «все»/«сбросить»; выбранные значения
показываются чипсами над KPI. `range` и `daterange` — два поля «от» и «до», любое
можно оставить пустым. `search` — подстрока без учёта регистра.

Фильтры складываются по «И». Кросс-фильтрация по клику на графике кладётся в тот
же набор, поэтому клик по столбцу и галочка в списке — это одно и то же
состояние.

## kpis

```json
{"label": "Выручка", "column": "Выручка", "agg": "sum", "format": "money"}
```

| Поле | Смысл |
|---|---|
| `label` | Подпись карточки |
| `column` | Числовая колонка; не нужна для `count` |
| `agg` | `sum` · `avg` · `count` · `count_distinct` · `min` · `max` · `median`. По умолчанию `sum`, а без `column` — `count` |
| `format` | См. [форматы](#форматы-значений) |
| `hint` | Подпись мелким шрифтом под числом |

Под аддитивными KPI (`sum`, `count`, `count_distinct`) при активных фильтрах
автоматически появляется доля от всех данных. Для `avg`/`median`/`min`/`max`
доля не выводится: «среднее — 100,2 % от всех данных» ничего не означает.

## charts

### Общие поля графика

| Поле | По умолчанию | Смысл |
|---|---|---|
| `type` | — | Тип блока (обязательно) |
| `title` | тип | Заголовок карточки |
| `note` | — | Пояснение под заголовком: методика, оговорка, единицы |
| `span` | `6` | Ширина в сетке из 12 колонок; на узком экране всё разворачивается на всю ширину |
| `height` | `280` | Высота области рисования, px |
| `measure` | — | Числовая колонка, которую агрегируем; без неё считаются записи |
| `agg` | `sum` (или `count` без `measure`) | Агрегат |
| `format` | — | Формат подписей значений |

### Поля по типам графика

**`bar`, `hbar`** — сравнение категорий. `hbar` берут, когда подписи длинные.

| Поле | Смысл |
|---|---|
| `dimension` | Разрез (обязательно) |
| `limit` | Оставить топ-N, остальное свернуть в «Прочие» |
| `other` | `false` — не показывать «Прочие», просто отбросить хвост |
| `sort` | `desc` (по умолчанию) · `asc` · `label` |
| `color` | Один цвет для всех столбцов вместо палитры |

**`line`, `area`** — динамика. Ось `dimension` должна быть датой.

| Поле | Смысл |
|---|---|
| `dimension` | Колонка-дата |
| `bucket` | `day` · `week` · `month` · `quarter` · `year`; без него подбирается по длине периода |
| `series` | Разбить на несколько линий по этой колонке (максимум 8 крупнейших) |

**`stacked-bar`** — вклад составляющих.

| Поле | Смысл |
|---|---|
| `dimension` | Ось категорий или дат |
| `series` | Чем набирается стопка (обязательно) |
| `stack` | `percent` — стопки до 100 %, сравниваются структуры, а не объёмы |

**`pie`, `donut`** — доли целого. Больше 6–7 секторов не читаются: ставь `limit`.
`donut` показывает в центре сумму.

**`scatter`** — связь двух числовых величин.

| Поле | Смысл |
|---|---|
| `x`, `y` | Числовые колонки (обязательно) |
| `series` | Цвет точек по категории |
| `size` | Числовая колонка — радиус точки |

**`histogram`** — распределение одной числовой величины.

| Поле | Смысл |
|---|---|
| `column` | Числовая колонка (обязательно) |
| `bins` | Число интервалов; по умолчанию ≈ √N |

**`heatmap`** — пересечение двух разрезов.

| Поле | Смысл |
|---|---|
| `dimension` | Строки |
| `series` | Столбцы (обязательно) |
| `limit` | Сколько строк оставить (по умолчанию 15; столбцов — до 20) |

**`table`** — детализация под графиками.

| Поле | Смысл |
|---|---|
| `columns` | Какие колонки показать; по умолчанию первые восемь |
| `sortBy` | Колонка сортировки при открытии |
| `pageSize` | Строк на странице (по умолчанию 25) |

Таблица всегда получает поиск, сортировку по клику на заголовке и постраничную
навигацию — описывать это в конфиге не нужно.

## Форматы значений

| `format` | Вид | Когда |
|---|---|---|
| `money` | `42,68 млн ₽` | Деньги |
| `compact` | `42,68 млн` | Крупные величины без валюты |
| `int` | `7 704` | Штуки, количества |
| `percent` | `17,7 %` | Доли; значение хранится как `0.177`, а не `17.7` |
| не задан | `1 234` / `12,34` | Обычные числа |

## Полный пример

```json
{
  "title": "Продажи 2025",
  "subtitle": "1 200 сделок · январь–декабрь 2025",
  "filters": [
    {"column": "Дата"},
    {"column": "Регион"},
    {"column": "Категория"},
    {"column": "Выручка", "type": "range"}
  ],
  "kpis": [
    {"label": "Выручка", "column": "Выручка", "agg": "sum", "format": "money"},
    {"label": "Прибыль", "column": "Прибыль", "agg": "sum", "format": "money"},
    {"label": "Сделок", "agg": "count"},
    {"label": "Средний чек", "column": "Выручка", "agg": "avg", "format": "money"}
  ],
  "charts": [
    {"type": "line", "title": "Динамика выручки по месяцам", "dimension": "Дата",
     "bucket": "month", "measure": "Выручка", "agg": "sum", "format": "money", "span": 8},
    {"type": "donut", "title": "Структура по каналам", "dimension": "Канал",
     "measure": "Выручка", "agg": "sum", "span": 4},
    {"type": "hbar", "title": "Топ регионов", "dimension": "Регион", "measure": "Выручка",
     "agg": "sum", "limit": 10, "format": "money", "span": 6},
    {"type": "stacked-bar", "title": "Категории внутри регионов", "dimension": "Регион",
     "series": "Категория", "measure": "Выручка", "agg": "sum", "stack": "percent", "span": 6},
    {"type": "heatmap", "title": "Менеджеры × категории", "dimension": "Менеджер",
     "series": "Категория", "measure": "Прибыль", "agg": "sum", "span": 7},
    {"type": "scatter", "title": "Выручка и прибыль сделок", "x": "Выручка", "y": "Прибыль",
     "series": "Категория", "span": 5},
    {"type": "table", "title": "Сделки", "sortBy": "Выручка", "span": 12,
     "columns": ["Дата", "Регион", "Категория", "Менеджер", "Количество", "Выручка", "Прибыль"]}
  ]
}
```
