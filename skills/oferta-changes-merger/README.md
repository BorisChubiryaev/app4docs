# Oferta Changes Merger

Навык для кодинг-агента (GigaCode Desktop, Claude Code и совместимых):
собирает утверждённые документы «Изменения» в объединённый файл и обновляет
текст публичной оферты «Удобный доступ» с выделением правок цветом.

Исходная Оферта не изменяется. Юридический текст берётся только из документов
«Изменения» — навык не переформулирует и не дополняет его.

## Требования

- кодинг-агент с доступом к локальным файлам и запуску команд;
- Python 3.11 или новее.

Внешние пакеты, сеть и платные API не нужны.

## Установка

Скопируйте каталог `oferta-changes-merger` в каталог навыков вашего агента,
например:

```bash
cp -r oferta-changes-merger ~/.gigacode/skills/
# либо
cp -r oferta-changes-merger ~/.claude/skills/
```

Должен появиться каталог с файлом `SKILL.md` внутри. Перезапустите сессию
агента, чтобы он перечитал список навыков.

## Пример вызова

```text
Собери изменения в оферту. Действующая Оферта — /путь/Приложение7.docx,
документы с изменениями — /путь/Изменения74.docx и /путь/Изменения75.docx.
Результат положи в /путь/out/: обновлённую Оферту, объединённый файл
изменений и отчёт.
```

Ожидаемые файлы:

- `oferta_izmenennaya.docx` — текст Оферты с выделенными правками;
- `obedinennye_izmeneniya.docx` — перечень правок в порядке пунктов Оферты;
- `report.md` — отчёт с инвариантами и предупреждениями.

## Что умеет

| Операция | Инструкция в документе «Изменения» |
|---|---|
| Вставка после слов | «после слов «…» дополнить…» — в пункте или сноске |
| Новая редакция пункта | «п. X изложить в следующей редакции» |
| Новая редакция сноски | «Изложить сноску N в следующей редакции» |
| Новый пункт | «Дополнить пунктом X с перенумерацией» |
| Новая сноска | «после слов «…» дополнить сноской» |
| Изменение строк таблицы | «Приложение N … пункты 3, 4 … изложить» |
| Добавление строк | «Дополнить таблицу … строками X–Y» |
| Алфавитная сортировка | «изложить в алфавитном порядке с изменением нумерации» |
| Вставка по алфавиту | «дополнить … в алфавитном порядке» |

Нумерация пунктов и сносок пересчитывается Word автоматически: новый абзац
наследует нумерацию соседнего, а сноски нумеруются по порядку ссылок.

## Ручная проверка

```bash
python3 scripts/ofertamerge.py --help
python3 -m unittest scripts/test_ofertamerge.py -v
```

## Гарантии и ограничения

Инструмент не перезаписывает исходник, сверяет его SHA-256, проверяет
целостность XML и частей пакета, а также инварианты приложений: отсутствие
утраченных записей, непрерывность нумерации и алфавитный порядок там, где он
запрошен.

Строки таблиц опознаются по **наименованию компании**, а не по номеру: номера
в документах «Изменения» относятся к другой редакции. Если под указанным
номером стоит другая компания, строка не изменяется, и это попадает в отчёт.

Навык не выполняет юридическую экспертизу, не оценивает применимость правки
по существу и не редактирует автоматически поля Word, рисунки и встроенные
объекты. Инструкции, не сводящиеся к каталогу операций, выносятся в отчёт для
ручной обработки.
