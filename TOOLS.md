# Что умеет Convertix

Convertix объединяет 13 инструментов для работы с таблицами, документами, изображениями и презентациями. Откройте главную страницу приложения, выберите инструмент по названию и нажмите **«Открыть»**. Для работы с файлами достаточно браузера.

## Таблицы и сверка данных

### Сравнение Excel/Word/PDF-файлов

Когда приходят две версии документа, загрузите старую и новую. Для Excel выберите листы — инструмент сопоставит строки и подсветит изменённые ячейки. Вставка строки посередине таблицы учитывается при сравнении следующих строк.

Word и PDF можно сверять между собой. Например, можно проверить подписанный PDF по исходному файлу Word. Результат показывает изменения в абзацах и таблицах, а для PDF указывает страницы. Если подписанный экземпляр отсканирован, сначала добавьте текстовый слой через **PDF Studio**.

### Сравнение Excel-файлов по рабочим местам

Для двух выгрузок из АС «Друг» предусмотрена отдельная сверка. Загрузите версии «было» и «стало», чтобы увидеть, какие позиции появились, исчезли или изменились. В изменённой позиции можно проверить прежние и новые значения, отобрать нужные строки фильтрами и выгрузить результат в Excel.

### Excel группиратор

Пригодится, когда несколько подразделений прислали сведения об одних и тех же сотрудниках. Загрузите Excel-файлы и задайте ключ для сопоставления, например ФИО и должность. Затем укажите столбцы, значения которых нужно собрать вместе. В итоговой таблице у каждого собранного значения будет номер исходного файла. Результат можно проверить на экране и скачать в Excel.

### Конвертер HTML/JSON-таблицы в Excel

Если данные пришли в виде кода веб-страницы или JSON, вставьте их в конвертер. В предпросмотре можно выбрать нужную таблицу, строки и столбцы, а затем скачать XLSX. Для HTML-таблиц конвертер переносит и оформление ячеек. Если таблицу на сайте строит скрипт после загрузки, в сохранённом HTML её может не оказаться.

## Документы и отчёты

### PDF Studio

Используйте PDF Studio, когда результат нужен в том же формате. Например, для отправки договора с приложениями можно объединить несколько PDF, переставить или повернуть страницы, добавить нумерацию и сохранить один файл. Большой документ можно разделить на части и скачать их архивом.

Для сканов есть распознавание текста с поиском. Перед отправкой документа можно заполнить поля формы, нанести изображение подписи или печати, скрыть персональные данные инструментом вымарывания и сжать файл.

### Конвертер документов

Переводит **PDF в редактируемый Word** и **Word в PDF**. В первом случае конвертер восстанавливает текст и таблицы, а для сканов распознаёт русский и английский текст. Если в исходнике сложные колонки или таблицы с объединёнными ячейками, после конвертации стоит сверить их с оригиналом.

Обратное преобразование пригодится, когда согласованный DOCX нужно разослать как PDF. В результате сохраняются колонтитулы, текст можно искать и копировать. Можно обработать несколько файлов за один раз.

### Объединение изменений в оферту

Загрузите исходную оферту и документы Word с изменениями к ней. Инструмент разбирает указания о новой редакции пунктов, сносках и строках таблиц. В предпросмотре можно проверить, куда относится каждая правка, и выбрать изменения для применения.

На выходе два файла DOCX. Первый содержит сводный перечень изменений по пунктам оферты. Второй — обновлённый текст, где правки выделены цветом или оформлены в режиме исправлений Word.

### HTML-редактор

Позволяет поправить готовый HTML-отчёт прямо на странице. Откройте файл или вставьте код, дважды нажмите на текст, чтобы исправить формулировку. Можно заменить картинку, изменить цвета и шрифты, вставить диапазон из Excel в таблицу или обновить данные графика. Вкладка **«Просмотр»** показывает страницу с работающими скриптами.

Для дальнейших правок скачайте HTML. Для рассылки коллегам нажмите **«Скачать PDF»**. Редактор сохранит экранное оформление при выбранной ширине, разложит отчёт по листам A4 с полями и добавит текстовый слой для поиска и копирования.

## Графики, изображения и презентации

### Генератор графиков

Начните с таблицы XLSX, CSV или диапазона, скопированного из Excel. Выберите категории и числовые ряды. Например, чтобы показать продажи по регионам, можно суммировать значения по региону, отсортировать их и выделить лидера цветом. На одном холсте можно разместить несколько графиков, стрелки и пояснения.

Готовый график можно скопировать в презентацию, скачать в PNG или SVG. Если коллегам нужны и график, и исходные показатели, сохраните HTML-отчёт с таблицей данных.

### Графика для слайдов

Для отдельного слайда можно собрать анимированную воронку, карточку с ключевым показателем, обложку или карусель фотографий. Выберите шаблон, подставьте данные и настройте оформление. Статичный результат можно скачать в PNG с прозрачным фоном или в JPEG, анимацию — в видео. В браузерах с поддержкой нужного кодека доступен MP4.

Можно работать и со своей презентацией. Нажмите **«Открыть PPTX»**, выберите слайд и объект. В редакторе можно исправить текст, изменить цвет фигуры или палитру диаграммы, добавить анимированную графику и посмотреть её на слайде. При смене палитры диаграммы сохраняются её данные Excel. **«Скачать PPTX»** сохранит отдельную копию презентации. В каталоге инструмент помечен как тестовый.

### PDF → PowerPoint

Полезен, если от презентации остался только PDF. Каждая страница становится отдельным слайдом исходного размера. В режиме **«Редактируемая»** текст переносится в текстовые блоки, а изображения и поддерживаемые фигуры — в отдельные объекты PowerPoint. Сложные фрагменты могут переноситься картинками.

Режим **«Точная копия»** подходит, когда важнее внешний вид. Он сохраняет оформление страницы изображением и переносит имеющийся текст поверх. Если исходная страница целиком состоит из скана, в PPTX она также будет изображением.

### Перенос в шаблон

Когда изменился корпоративный шаблон, загрузите образец оформления в PPTX или POTX и одну или несколько исходных презентаций PPTX. Инструмент применит фон, шрифты, цвета и расположение заголовков из образца. Несколько презентаций можно собрать в один файл, сохранив для каждой свой раздел. На выходе — презентация PowerPoint в едином оформлении.

### Универсальный конвертер изображений

Принимает SVG, PNG, JPEG, WebP, GIF, BMP, а также PDF и PSD. Например, из исходника дизайнера можно сделать PNG с прозрачным фоном для слайда, JPEG для письма или значок ICO. Для фотографий есть удаление фона.

Несколько изображений можно собрать в один PDF. Выберите порядок, раскладку на листе, подписи и нумерацию — получится иллюстрированное приложение к отчёту.

## Игры для перерыва

Пять дополнительных разделов открываются кнопкой **«Игры»** внизу главной страницы.

| Раздел | Что можно сделать |
| --- | --- |
| Шахматы | Сыграть против компьютера, выбрать цвет и один из шести уровней сложности. Сохранённую партию можно продолжить позже. |
| Уроки шахмат | Решать задачи на доске, получать подсказки и объяснения ходов. Прогресс сохраняется в браузере. |
| Шашки | Сыграть против компьютера по правилам русских шашек. Игра подсказывает обязательные взятия и позволяет продолжить сохранённую партию. |
| Змейка | Собирать значки файлов, ловить временные бонусы и переходить на следующий уровень. |
| Три в ряд | Составлять комбинации из одинаковых фишек и набирать очки для перехода на следующий уровень. |
