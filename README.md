# EX-EL — Набор инструментов для работы с документами

## Установка

1. Клонируйте репозиторий:

   ```bash
   git clone <url-репозитория>
   cd app4docs
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Запустите сервер разработки:

   ```bash
   npm run dev
   ```

4. Откройте в браузере:
   ```
   http://localhost:5173
   ```

## Запуск в режиме разработки

### Веб-версия (браузер)

```bash
npm run dev
```

### Electron (десктопное приложение)

```bash
npm run electron:dev
```

## Сборка

### Веб-версия (для деплоя или QlikSense)

```bash
npm run build
```

Результат — папка `dist/`. Для QlikSense:

```bash
node dist-utils/index.cjs
```

### Десктопное приложение (.app для macOS)

```bash
npm run electron:build:dir
```

Результат — `release/mac/Apps4Excel.app`.

### DMG-образ для macOS

```bash
npm run electron:build:dmg
```

Результат — `release/Apps4Excel-1.0.0.dmg`.

> **Примечание:** DMG собирается через встроенный `hdiutil`. Скрипт `scripts/build-dmg-only.sh` создаёт DMG с ярлыком Applications для стандартной установки перетаскиванием.

Если нужно собрать только DMG из уже готового `.app`:

```bash
bash scripts/build-dmg-only.sh
```

### Windows

```npm run electron:build:win

```

### Linux

```npm run electron:build:linux

```

# Инструменты

## 🧩 Инструмент №1: Сравнение рабочих мест

_Сравнивайте выгрузки из АС «Друг» за секунды — без ручного поиска изменений._

**Как это работает:**

1.  Загружаете два Excel-файла с выгрузками по рабочим местам.
2.  Алгоритм автоматически сопоставляет позиции и находит все изменения.
3.  Результат — наглядная таблица с подсветкой:
    - 🔴 Было
    - 🟢 Стало
    - 🔵 Новая
    - 🟡 Удалена

**✨ Особенности:**

- Фильтры формируются динамически на основе ваших данных.
- Гибкая настройка.
- Мгновенный экспорт результата в Excel.

ℹ️ _Подробная инструкция доступна в верхнем, правом углу._

## 🧾 Инструмент №2: Универсальное сравнение документов

_Сравнивайте любые пары файлов — Excel с Excel, Word с Word — и мгновенно находите каждое изменение._

**Как это работает:**

1.  Загружаете два документа любого объёма.
2.  Система выполняет поточное сравнение: сопоставляет строки, ячейки и абзацы по позициям.
3.  Результат отображается в удобном режиме side-by-side с цветовой подсветкой.

**✨ Особенности:**

- Точное сравнение по структуре, а не только по тексту (учитывает расположение в ячейках/строках).
- Просмотр «до/после» в одном окне — легко отследить контекст изменений.
- Подходит для контрактов, регламентов, таблиц с данными — всего, где важна каждая правка.
- Всё происходит локально: ваши документы никогда не покидают браузер.

💡 _Идеально для согласования версий с коллегами, контроля правок юристов или отслеживания изменений в шаблонах._ 📊

## 🧾 Инструмент №3: Конвертер HTML → Excel

_Извлекайте таблицы с любых сайтов в один клик — без копирования вручную и форматирования._

**Как это работает:**

1.  Вставляете HTML-код страницы (скачать страницу можно нажатием `Cmd+S` или `Ctrl+S`).
2.  Система автоматически находит все таблицы на странице и показывает их в предпросмотре.
3.  Выбираете нужную таблицу (или несколько) и настраиваете экспорт:
    - 🎯 Фильтр по строкам и колонкам — берите только нужное.
    - 🔍 Поиск по содержимому таблиц — быстро найдёте нужную.
    - 🎨 Сохранение стилей и форматирования.
4.  Скачиваете готовый Excel-файл.

**✨ Особенности:**

- Предпросмотр всех найденных таблиц перед загрузкой.
- Гибкий конструктор: отберите только нужные колонки и строки.
- Поддержка стилей — таблицы сохраняют внешний вид оригинала.
- Полностью локальная обработка: никаких отправок на сервер.

**💡 Идеально для:**

- Выгрузки прайс-листов, рейтингов, статистики с сайтов.
- Анализа данных из открытых источников.
- Быстрого переноса информации в удобный формат.

⚠️ _Примечание: Динамические таблицы (подгружаемые через JavaScript) могут не находиться алгоритмом._

**✨ Особенности:**

- Поддержка загрузки файла и вставки кода — как удобнее.
- Точный контроль над размерами без потери качества.
- Прозрачный фон в PNG для логотипов и иконок.
- Мгновенная конвертация прямо в браузере — без ожидания.
- Полная приватность: изображения не покидают ваш компьютер.

**💡 Идеально для:**

- Подготовки логотипов для презентаций и сайтов.
- Экспорта иконок в нужном разрешении.
- Быстрого преобразования векторных схем для отчётов.

**✨ Особенности:**

- Максимальная эффективность для сканированных документов и файлов с картинками.
- Настройка баланса «размер ↔ качество» (авто-режим подбирает оптимально).
- Мгновенная обработка прямо в браузере — чем больше файл, тем заметнее выгода.
- Полная конфиденциальность: документ никогда не покидает ваш компьютер.

**💡 Идеально для:**

- Отправки сканов по почте с ограничением вложения.
- Загрузки документов в системы с лимитом размера.
- Хранения архивов без переполнения диска.

3.  Скачиваете готовый документ — мгновенно и без водяных знаков.

**✨ Особенности:**

- Интуитивный интерфейс «перетащи и отпусти» для страниц.
- Предпросмотр каждой страницы перед финальной сборкой.
- Обработка полностью в браузере — ваши документы не уходят на серверы.
- Поддержка файлов любого размера (ограничено возможностями браузера).
- Результат сохраняется в исходном качестве.

**💡 Идеально для:**

- Формирования пакетов документов (резюме + диплом + сертификаты).
- Подготовки отчётности из нескольких источников.
- Удаления сканов-дубликатов или пустых страниц.
- Быстрой сборки презентаций и договоров перед отправкой.

🔒 _Важно: Все операции происходят локально — ваша конфиденциальная документация остаётся только у вас._

## 🧮 Инструмент №7: Excel-группиратор

_Объединяйте данные из нескольких Excel-файлов в единую таблицу — с автоматической нумерацией и сохранением источника каждой записи._

**Как это работает:**

1.  Загружаете несколько Excel-файлов (например, выгрузки за разные периоды или от разных подразделений).
2.  Настраиваете колонки:
    - 🔑 **Ключи группировки** — колонки, по которым строки объединяются (например: код должности, подразделение, ФИО).
    - 🔗 **Колонки для группировки** — значения из этих колонок объединяются с указанием источника.
    - ➖ **Пропустить** — неиспользуемые колонки.
3.  Алгоритм автоматически сопоставляет строки по ключам и объединяет данные.
4.  Результат: одна таблица, где каждое значение помечено номером файла-источника (формат: `1.1. Значение`, `2.3. Значение`).

**✨ Особенности:**

- Сохранение контекста: сразу видно, из какого файла какое значение пришло.
- Гибкая настройка: выбирайте любые колонки как ключи или для группировки.
- Автоматическое разбиение: значения из ячеек с разделителями (`, ; ；`) автоматически разделяются и нумеруются.
- Предпросмотр: перед скачиванием видите итоговую таблицу.
- Экспорт в Excel с форматированием и подсветкой заголовков.

**💡 Идеально для:**

- Сравнения штатных расписаний за разные периоды.
- Объединения данных от нескольких подразделений.
- Анализа изменений в справочниках и реестрах.
- Формирования сводных отчётов из разрозненных источников.

📊 **Пример использования:** Загрузили 3 файла с данными по сотрудникам → объединили по ключам (ФИО, должность) → в колонке «Образование» получили: `1.1. Высшее`, `2.1. Среднее специальное`, `3.1. Высшее` — сразу видно, где и что изменилось.

## 📊 Инструмент №8: Генератор графиков

_Создавайте графики и диаграммы прямо в браузере — без Excel, без PowerPoint, без регистрации._

**Как это работает:** 0. Загрузите табличные данные и выберите данные для осей.

1.  Выбираете тип графика:
    - 📊 Столбчатая диаграмма (вертикальная / горизонтальная)
    - 📈 Линейный график
    - 🟢 Точечная диаграмма
    - 🥧 Круговая / кольцевая диаграмма
    - 📐 Диаграмма с областями
    - 📊 Комбинированный график (столбцы + линия)
2.  Настраиваете внешний вид:
    - 🎨 Цвета серий, фона, сетки
    - 🏷️ Заголовок, подписи осей, легенда
    - 📏 Размеры, отступы, скругления
    - 🔤 Шрифты и размеры текста
3.  Скачиваете результат как PNG-изображение в высоком разрешении — готово для вставки в презентацию, отчёт или документ. Либо экспортируйте график в отдельной вкладке, в браузере.

**✨ Особенности:**

- Мгновенный предпросмотр: график обновляется в реальном времени при изменении данных или настроек.
- Множество серий данных: добавляйте сколько угодно рядов данных на один график для сравнения.
- Умный импорт из Excel: вставьте данные из таблицы — колонки и строки распознаются автоматически.
- Гибкая кастомизация: от цветов и шрифтов до позиции легенды и формата подписей.
- Экспорт в PNG: высококачественное изображение, готовое для печати и презентаций.
- Работает офлайн: все вычисления и рендеринг — в браузере, данные никуда не отправляются.

**💡 Идеально для:**

- Быстрого создания графиков для презентаций и отчётов.
- Визуализации данных из Excel без открытия Excel.
- Подготовки диаграмм для вставки в Word, PowerPoint, PDF.
- Сравнения показателей по периодам, подразделениям, категориям.
- Ситуаций, когда нет доступа к Excel или специализированным BI-инструментам.
